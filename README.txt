                             AllBinary Platform Component Pascal (Ofront+)

What is it?

This repository contains code generated by the AllBinary Platform for support in Component Pascal (Ofront+).  
This repo is used to allow developers to skip the Component Pascal (Ofront+) code generation step.

What are some example games with this Component Pascal (Ofront+) code?

https://allbinary.itch.io (The downloads with "-componentpascal" in the filename are Component Pascal (Ofront+) only builds. Currently that only includes nothing. Also the Component Pascal (Ofront+) builds are not available on Google Play or other stores.)
